# Reports

This folder has the template and notes for documenting potentially harmful websites and online activity.

Before adding a report, read [CONTRIBUTING.md](../CONTRIBUTING.md) and [SECURITY.md](../SECURITY.md).

Only include findings when there's an actual reason to be concerned. Explain what you saw, don't overstate what it proves, and leave out private info, passwords, private messages, non-consensual images, and unsafe files.

Use [REPORT_TEMPLATE.md](REPORT_TEMPLATE.md) to get started. It's just a way to keep notes organized—it doesn't guarantee every finding is correct or that a platform will take action.
