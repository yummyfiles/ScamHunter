# Research

This folder tracks leads and what I've checked so far.

- `leads/2026-10-10.md` — initial candidates from a public phishing database.
- `malware-indicators/2026-10-10.md` — a malware indicator reported by ThreatFox.

A lead is **not automatically a confirmed harmful site**. Record where it came from, when it was checked, what the source actually says, and what still needs verification. Use defanged domains (for example, `example[.]com`) to reduce accidental clicks.

Don't interact with suspicious sites, submit personal information, download files, or publish private data to prove a point. Cross-check leads using reputable sources and keep uncertainty obvious.
