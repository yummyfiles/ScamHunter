# Research

This folder tracks leads and what we've actually checked so far.

- `leads/2026-10-10.md` — initial candidates from a public phishing database.

A lead is **not automatically a confirmed scam**. Record where it came from, when you checked it, what the source actually says, and what still needs verification. Use defanged domains (for example, `example[.]com`) to reduce accidental clicks.

Don't interact with suspicious sites, submit personal information, download files, or publish private data to prove a point. Cross-check leads using reputable sources and keep uncertainty obvious.
