# Sources and Reporting Channels

Use these resources as starting points. Their coverage, criteria, and response times differ; a listing or reputation score is not conclusive proof by itself.

## Reporting channels

- [Google Safe Browsing phishing report](https://safebrowsing.google.com/safebrowsing/report_phish/)
- [Microsoft report an unsafe site](https://www.microsoft.com/en-us/wdsi/support/report-unsafe-site)
- [FTC ReportFraud](https://reportfraud.ftc.gov/)
- [FBI Internet Crime Complaint Center (IC3)](https://www.ic3.gov/)
- [CISA reporting](https://www.cisa.gov/report)

## Reputation and threat intelligence

- [Google Safe Browsing](https://transparencyreport.google.com/safe-browsing/search)
- [VirusTotal](https://www.virustotal.com/) — URL and file reputation checks; review its privacy and sharing policies before submitting sensitive material.
- [URLhaus](https://urlhaus.abuse.ch/) — malware URL intelligence.
- [PhishTank](https://phishtank.org/) — community phishing data.

## Good practice

- Prefer original, authoritative sources and check when their data was last updated.
- Do not assume absence from a blocklist means a site is safe.
- Do not submit private or sensitive URLs to third-party scanners without checking their data-handling policies.
- Record the source and date of each lookup so results can be interpreted later.
