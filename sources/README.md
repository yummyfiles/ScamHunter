# Sources and Reporting Links

Here are some places to check a suspicious URL and report it if there's a real reason to. Each service works differently, so don't treat one score or listing as the final word.

## Report a site or incident

- [Google Safe Browsing — report phishing](https://safebrowsing.google.com/safebrowsing/report_phish/)
- [Microsoft — report an unsafe site](https://www.microsoft.com/en-us/wdsi/support/report-unsafe-site)
- [FTC ReportFraud](https://reportfraud.ftc.gov/)
- [FBI Internet Crime Complaint Center (IC3)](https://www.ic3.gov/)
- [CISA reporting](https://www.cisa.gov/report)

## Check a URL or threat feed

- [Google Safe Browsing](https://transparencyreport.google.com/safe-browsing/search)
- [VirusTotal](https://www.virustotal.com/) — checks URL and file reputation. Read its privacy and sharing policies before submitting anything sensitive.
- [URLhaus](https://urlhaus.abuse.ch/) — information about URLs used to distribute malware.
- [PhishTank](https://phishtank.org/) — community-submitted phishing data.
- [OpenPhish.eu](https://www.openphish.eu/) — community phishing reports and a public database. Check each entry's verification status; unverified submissions are only leads, not proof.

## A few things to keep in mind

- Prefer original, trustworthy sources and check when their info was last updated.
- Not being on a blocklist doesn't mean a website is safe.
- Don't send private or sensitive URLs to third-party scanners without checking what they do with submitted data.
- Keep track of which source you checked and when, so the result makes sense later.
